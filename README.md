# Freelancer Jakaria — Nexus Workspace

A responsive front-end prototype inspired by the supplied glassmorphism login, OTP, analytics dashboard and kanban/job-board references.

## Run
Open `index.html` in a modern browser. No build step is required.

## Demo access
- Email: `admin@freelancerjakaria.com`
- Password: `demo1234`

Registration demo OTP: `4719`

## Included
- Glassmorphism login, registration, OTP and forgot-password screens
- Responsive sidebar and dashboard
- Revenue overview, activity feed and KPI cards
- Orders, service catalogue, clients, tasks/kanban, team, invoices and settings
- Add/remove demo records with browser localStorage persistence
- Drag tasks between Kanban columns
- Mobile-responsive layout and ambient animated background

## Important production notes
This is a front-end prototype, not a production-secure business system. Authentication is demo-only and the OTP is hard-coded for preview. Google/Apple OAuth, real email/SMS OTP, password reset, database/API, role permissions, audit logs, file uploads, payment gateways, invoice PDF generation, hosting, HTTPS and backups must be implemented/configured before launch. Never use the demo credentials for a real account.
